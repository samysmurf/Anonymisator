# Testkonzept

Ausschließlich synthetische Dokumente verwenden. OCR: Soll-/Isttext, Umlaute, Tabellen, Spalten, Laufzeit und Speicherverbrauch prüfen. Schwärzung: nach Export Textsuche, Copy/Paste, OCR, Textlayer, Anhänge und Metadaten prüfen. Netzwerk: sicherstellen, dass vor einer Freigabe keine Dokumentinhalte übertragen werden. Kein Release einer Schwärzungsfunktion ohne reproduzierbare Negativtests.
