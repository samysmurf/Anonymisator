# Datenschutz und Sicherheit

Leitprinzip: lokale Verarbeitung, Datenminimierung und Nutzerkontrolle. Keine direkte KI-Schnittstelle und keine automatische externe Übertragung von Dokumentinhalten.

Nur synthetische oder vollständig anonymisierte Testdaten in GitHub verwenden. Originale unverändert lassen. Automatische Erkennung ist fehleranfällig; manuelle Kontrolle ist vor Export erforderlich. Schwärzung muss Text, Bildinhalt, OCR-Reste und Metadaten tatsächlich entfernen. Eine automatische Markierung beweist keine vollständige Anonymität.
