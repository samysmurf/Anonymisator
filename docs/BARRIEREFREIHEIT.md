# Barrierefreiheit – @Vision

Ziel: native Android-App mit TalkBack und weiteren Android-Zugangsformen bedienbar machen. Anforderungen: semantische Beschriftungen, logische Fokusreihenfolge, skalierbare Schrift, ausreichender Kontrast, keine allein farb- oder gestenabhängige Bedienung, textuelle OCR-Markierungen und verständliche Fehlermeldungen. Tests auf realen Geräten sind vor einer Konformitätsaussage erforderlich.
