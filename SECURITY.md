# Security Policy

Frühe Entwicklungsphase; keine unabhängige Sicherheitsprüfung oder Zertifizierung. Keine echten Bescheide, Gesundheitsdaten, Aktenzeichen, Zugangsdaten, Tokens oder privaten Schlüssel in Issues/PRs hochladen. Sicherheitsprobleme möglichst privat über GitHub melden. Lokale Verarbeitung ist ein Entwicklungsziel und muss später technisch getestet werden.
