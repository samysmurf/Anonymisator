# Anonymisator

Eigenständiges Android-Projekt zur lokalen Dokumentenverarbeitung. Ziel sind lokale Textextraktion/OCR, Erkennung sensibler Angaben, manuelle Prüfung, echte dauerhafte Schwärzung, Metadatenkontrolle und lokaler Export. **Frühe Entwicklungsphase:** native App, vollständige PDF-Pipeline und sichere Schwärzung sind noch nicht implementiert. Keine direkte KI-Schnittstelle und keine automatische Datenübertragung zu Student Müller.
